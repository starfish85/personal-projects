# 暑假签到打卡

晚上 21:30 在学校时，用**真实定位**自动走微信小程序「打卡签到表」。  
定位过远、控件找不到、结果不明确时，脚本会停下并震动提醒你手签。

这是手机无障碍自动点击，不是改定位，也不是破解小程序接口。人必须在学校，GPS 必须是真的。

适用：安卓手机 + 已登录的微信。电脑上的 Mac 只是用来改脚本，真正运行在手机上。

---

## 1. 手机上装什么

推荐装 **AutoJs6**（免费，能点微信）：

1. 用手机浏览器打开：https://github.com/SuperMonster003/AutoJs6/releases
2. 下载最新的 `autojs6-v*.apk` 并安装
3. 若系统拦未知来源，到设置里允许安装

没有 AutoJs6 时，**AutoX.js** 也可以，用法几乎一样。

不要装官方已下架、且屏蔽了微信的 Auto.js Pro 阉割版。

---

## 2. 把脚本拷到手机

把整个 `wechat-checkin` 文件夹放到手机，例如：

```text
/sdcard/脚本/wechat-checkin/
    main.js
    config.json
    project.json
    dump_ui.js
    README.md
```

拷法任选：

- 用微信文件传输助手发这个文件夹到手机
- 数据线连电脑后拖进手机「脚本」目录
- Mac 上：`adb push wechat-checkin /sdcard/脚本/`

然后打开 AutoJs6 → 右上角刷新 → 应能看到「暑假签到打卡」。

---

## 3. 必须打开的权限

在 AutoJs6 里把下面全部打开，缺一个晚上都会静默失败：

| 权限 | 为什么 |
|---|---|
| 无障碍服务 | 才能点微信按钮 |
| 后台弹出界面 | 锁屏后才能拉起微信（小米 / vivo / OPPO / 荣耀尤其要开） |
| 显示悬浮窗 | 控制台、截图授权 |
| 忽略电池优化 | 21:30 不被系统杀掉 |
| 通知权限 | 失败时能弹提示 |

微信和系统里再确认：

- 微信已登录，能手点打开「打卡签到表」
- 系统定位开关打开，微信定位权限为「使用时允许」或「始终允许」
- 精确位置打开

厂商后台锁（按你的系统找类似入口）：

- 小米 / 红米：安全中心 → 授权管理 → 自启动 + 后台弹出
- OPPO / 一加 / 真我：应用启动管理 → 关闭智能限制，允许自启动/关联启动
- vivo / iQOO：后台高耗电、自启动
- 华为 / 荣耀：应用启动管理 → 手动管理，三项全开
- AutoJs6 在最近任务里**上锁**，防止被划掉

## 4. 先改配置

编辑 `config.json`：

```json
{
  "name": "刘海欣",
  "className": "计算机类2503班",
  "dryRun": true,
  "showConsole": true,
  "swipeUnlock": true
}
```

- `className` 必须和你**手签成功**的那一串完全一致。填写页截图里是 `计算机2503班`（没有「类」），如果你手签用的是带「类」的，再改回来。
- **第一次务必 `dryRun: true`**：脚本会填完表单，但不会点最后的「确定」。
- 锁屏只有上滑、没有密码/图案时，才把 `swipeUnlock` 保持为 `true`。有密码的手机，AutoJs6 **解不开**，见下一节。

---

## 5. 锁屏怎么办

脚本不能输入锁屏密码。21:30 要跑通，选一种：

1. **最稳**：晚上把手机插电放桌上，关闭锁屏，或设成「充电时不锁屏」
2. 只用上滑解锁，不设密码（宿舍里自己评估风险）
3. 21:25 先自己解锁，让屏幕亮着等到 21:30

不要指望它半夜隔着密码自己进去。

---

## 6. 第一次怎么试

人在学校、定位正常时，自己走一遍：

1. 打开 AutoJs6，点 `main.js` 运行
2. 第一次会申请截图权限，点允许
3. 看着它打开微信 → 小程序 → 填写页
4. `dryRun: true` 时，填完会停住并提示演练结束
5. 打开 `wechat-checkin/logs/last_result.txt` 看结果
6. 失败时同一目录会有截图和 `run.log`

确认姓名、定位、班级都对了，再把 `dryRun` 改成 `false`，再手动跑一次，看是否真的提交成功。

某一步卡住时，先手动停在那一页，运行 `dump_ui.js`，把 `logs/ui-dump.txt` 拿来对照。常见原因是微信改版后「搜索」找不到，或小程序控件没暴露文字。

---

## 7. 设每天 21:30

1. AutoJs6 首页点 `main.js` 右边的菜单
2. 选 **定时任务**
3. 周期选每天，时间 `21:30`
4. 保存

设完后不要强制停止 AutoJs6。前几天 21:25 看一眼手机：屏幕亮了没有、微信起来了没有、`last_result.txt` 写了什么。

---

## 8. 它实际会做什么

```text
点亮屏幕
→ 打开微信并回到主界面
→ 下拉最近使用，找不到就搜索「打卡签到表」
→ 活动首页：已签则退出；有广告则滑开；点「点击签到」
→ 填写页：姓名、定位（地图右上角「完成」）、班级
→ 点最底下「确定」（dryRun 时跳过）
→ 认「签到成功 / 距离过远 / 签到失败」
→ 震动 + 写 logs/last_result.txt
```

定位页等约 2.5 秒再点「完成」，用的是手机当时的真实 GPS。不在学校就会走「距离过远 → 请手签」。

---

## 9. 做不到的事

- 解开带密码的锁屏
- 伪造定位、离校打卡
- 保证微信/小程序改版后永远可用
- 在 iPhone 上运行（这是安卓无障碍脚本）

微信改版后如果突然找不到按钮，先跑 `dump_ui.js`，再改 `main.js` 里对应的文字。

---

## 10. 建议你这样验收

| 次数 | 设置 | 你要看到 |
|---|---|---|
| 第 1 次 | `dryRun: true`，人在学校，自己点运行 | 表单填好，没提交 |
| 第 2 次 | `dryRun: false`，人在学校，自己点运行 | `last_result.txt` 为签到成功 |
| 第 3 次 | 定时 21:30，人在学校 | 不用手点也能成功 |
| 任意一次失败 | — | 手机会震动，你立刻手签 |

前几天不要完全放手。脚本是省掉点选，不是把考勤责任交出去。
