> PRD 规定「有什么、规则是什么」。  
> **交互设计规定「屏幕上怎么摆、手指怎么点、每一种状态长什么样」。**  
> 企业里这一步通常在 Figma 出线框和原型。本项目用一份说明 + 一个可打开的低保真原型代替。  
> 仍然不是正式开发：原型里的分类和看图都是假的，数据关页即丢。

## 1. 这一步在企业里做什么

| 产出 | 给谁用 |
|---|---|
| 页面框架、组件 | 开发按这个拆界面，不自己发明第三页 |
| 全部状态稿 | 评审时把空、加载、失败翻一遍，避免只画了「有数据的幸福页」 |
| 关键交互（点、滑、反馈） | 开发知道点了会发生什么，测试知道要点哪里 |
| 轻量视觉（色、字、间距） | 小团队没有专职视觉时，全栈按 token 实现，不现场配色 |

需求评审已经点名必须覆盖的状态，本节全部落地，不增页、不增功能。

## 2. 交互原则（做界面时的口头禅）

1. **收录不打断。** 保存立刻进列表，分类转圈只发生在标签上，不弹全屏挡操作。
2. **永远能抄到一句。** 配图页不允许只有报错、没有句子。
3. **同一件事不要两个主按钮。** 封面记句子的入口是太阳；写字处的主按钮才是「保存」。配图页的主按钮是「复制」。
4. **字少、像人话。** 不出现「请求失败 error 500」。
5. **手指能点中。** 主操作热区至少约 44px 高；金句正文在配图页可长按选中。
6. **先手机。** 按一列手机宽度设计；桌面只是把同一列居中，不做复杂三栏后台。

## 3. 全局框架

软件名叫 **片语**。打开先看到安静的封面：一颗向外散光的太阳。没有标题栏。

```text
┌─────────────────────────┐
│                         │
│         ◎ 太阳           │  光圈持续往外散
│                         │
│      按图配文            │  文字按钮，去子页。封面不放操作说明
└─────────────────────────┘
```

点太阳后，太阳打开成写字处；保存或收起，回到太阳。  
上滑（或滚轮向下）进入现在的句子列表；列表顶「下滑回到太阳」。

```text
┌─────────────────────────┐
│ 下滑回到太阳             │
│ 筛选 / 句子卡片 / 复制   │
│                         │
│      【 按图配文 】      │  列表里仍用底部悬浮按钮
└─────────────────────────┘
```

进入按图配文后：

```text
┌─────────────────────────┐
│  ← 返回     按图配文     │
├─────────────────────────┤
│  上传 / 推荐 / 列表      │
└─────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 产品名 | 片语（浏览器标题、主屏幕名称，不出现在首页顶栏） |
| 默认页 | 太阳封面。点太阳才能写；上滑才见列表 |
| 进入配图 | 封面用「按图配文」文字按钮；列表里用底部悬浮按钮（不随滚动） |
| 返回配图 | 配图页左上角「← 返回」，回到离开前的封面或列表 |
| 列表避让 | 列表底部留白，最后一条不被悬浮按钮挡住 |
| 刷新 | 金句还在；配图页的图可以消失；打开仍先落在太阳封面 |
| 桌面 | 内容区最大宽度 430px 居中 |

## 4. 组件清单

企业里交互会先拆组件，开发才能按同一套积木做，而不是每页一种按钮。

| 组件 | 用在哪 | 要点 |
|---|---|---|
| 顶栏 | 仅配图页 | 首页无标题栏。配图页：← 返回 + 按图配文 |
| 太阳 | 封面 | 正圆光晕（不要拉成椭圆）。从中心散开，铺过整页后在屏幕外淡掉。点击中心进入写字 |
| 封面配图按钮 | 封面 | 太阳下方，描边文字按钮「按图配文」 |
| 悬浮按钮 | 仅列表 | 钉在底部，文案「按图配文」，不随列表滚动 |
| 录入框 | 点太阳后 | 多行，在发光卡片里；保存 / 收起 |
| 保存按钮 | 录入区 | 主色；空内容时禁用，不是点了才骂人 |
| 标签 | 列表、编辑、推荐卡 | 场景、情绪同一种小胶囊，情绪略强调即可 |
| 建议芯片 | 分类没把握 | 浅描边，点一下即采用 |
| 筛选条 | 片语 | 两个选择器：场景、情绪；默认「全部」 |
| 金句卡片 | 两页列表 | 正文 + 标签；片语点卡片进编辑；配图页正文可选择 |
| 复制按钮 | 两页都有 | 配图页：实心主色（本页主操作）。片语：文字按钮，放在标签右侧，避免和「保存」抢 |
| 空状态 | 两页 | 一句话 + 必要时一个行动（去片语） |
| 上传区 | 配图页 | 虚线框，未选图时很大；选中后变缩略图 + 换一张 |
| 推荐卡 | 配图页上部 | 比列表卡片略大，复制是主按钮 |
| 底部面板 | 编辑一条 | 从底部滑出，含改正文、场景、情绪、保存、删除 |
| 确认框 | 删除 | 短问句 + 删除 / 取消 |
| 轻提示 | 全局 | 底部浮出一句，约 2 秒；不挡保存和复制 |

## 5. 片语

### 5.0 封面（打开软件）

- 只见太阳和「按图配文」。不见列表、不见标题、不放「点太阳 / 上滑」这类说明。
- 太阳必须动：光圈一层层往外散、渐渐隐去，循环。尊重系统「减少动态效果」时可停动画、留下淡圈。
- **点太阳** = 记一句（打开写字处）。
- **上滑** = 进入句子列表。
- 封面的按图配文是次要入口，不要做成和太阳一样大的实心主按钮。

### 5.1 空列表（上滑之后库仍是空的）

```text
┌─────────────────────────┐
│ 下滑回到太阳             │
│  还没有金句。            │
│  冒出一句，回到太阳记下。 │
│      【 按图配文 】      │
└─────────────────────────┘
```

- 筛选条 **不出现**（没有句子可筛）。
- 记句子不在这页顶部，要回到太阳点一下。

### 5.2 有数据（默认列表）

- 筛选条出现。
- 列表按创建时间倒序。
- 卡片展示：正文（最多约 4 行，超出结尾省略）+ 场景标签 + 情绪标签。
- 点卡片进入编辑，不在列表上放删除图标（防误触）。
- 每张卡片标签右侧有文字按钮「复制」。点复制只抄正文、不打开编辑。不配图、只发圈时走这里。
- 片语主按钮仍是「保存」；库页的复制不用实心主色。底部「按图配文」是去另一页的入口，不是本页的第二个主操作。

### 5.3 刚保存 · 分类中

- 输入框清空，新卡片已在最顶。
- 标签位置显示「分类中…」，可带很轻的等待，**不盖住整页**。
- 此时用户可以继续打下一句，也可以点进这条去手动改分类（用户优先，见 PRD）。

### 5.4 分类完成

- 「分类中」换成真实标签。
- 无额外弹窗，无「分类成功」。

### 5.5 没把握 · 其他 + 建议

- 标签为「其他」（场景和/或情绪）。
- 卡片下方最多 2 个建议芯片，例如「建议：夜色城市」。
- 点芯片：立即换标签，视为用户指定，芯片消失。
- 不点也可以，句子照常用。

### 5.6 筛选无结果

- 筛选条保持当前选择。
- 列表区：「这个分类下还没有句子。可换成全部，或先去记一句。」
- 提供「换成全部」文字按钮，一点就把两个筛选打回全部。

### 5.7 编辑面板

从底部滑出，背后列表变暗，点遮罩 = 取消（不保存）。

| 区 | 交互 |
|---|---|
| 正文 | 多行编辑，右下角 `已用/500`；到 500 不能再输入 |
| 场景 | 词表芯片，最多 2 个真实场景；点「其他」则清空真实场景只留其他；点真实场景则去掉「其他」 |
| 情绪 | 词表芯片，单选，必须有 1 个 |
| 保存修改 | 主按钮；正文为空时禁用 |
| 删除 | 次要、危险色文字，不和保存抢 |

场景芯片在已选满 2 个时，未选项看起来不可点；先取消一个再选别的。

### 5.8 删除确认

「删除这句？删除后配图时不会再出现。」  
主操作是「取消」（安全），「删除」是危险次要。确认后面板关闭，列表去掉这条。

## 6. 按图配文

### 6.1 空库

- 仍能看到上传区，但结果区先占住：
  - 「库是空的，现在配不出句子。」
  - 按钮：「返回记一句」
- 若用户仍上传：缩略图可以出，结果区继续空库文案，不假装匹配。

### 6.2 未上传（库非空）

```text
┌─────────────────────────┐
│ ← 返回      按图配文    │
│ ┌─────────────────────┐ │
│ │   上传一张朋友圈图   │ │
│ │   从自己的句子里配   │ │
│ └─────────────────────┘ │
└─────────────────────────┘
```

- 虚线框整块可点，调起系统相册（单选）。
- 其下暂时没有推荐、没有列表。

### 6.3 匹配中

- 缩略图已出现，旁有「换一张」。
- 结果区：「正在看图找句子…」可用骨架卡片，**禁止整页空白**。
- 「换一张」在匹配中也可点：取消当次等待，重新开始。

### 6.4 把握高

- 标题：「比较适合这张图的几句」（P0 不跟具体标签；P1 再在标题旁加场景·情绪）
- 最多 3 条推荐卡，每条：正文（可长按选中）+「复制」
- 下方「相关分类里的全部文案」+ 列表（允许和推荐重复）
- 库 < 20 条时，列表不得省略。

### 6.5 把握中

- 标题仍是「比较适合这张图的几句」
- 推荐区可以更克制（同样最多 3 条）
- **列表是视觉重心**（间距、标题「相关分类里的全部文案」更醒目）

### 6.6 把握低

- 标题：「没找到特别贴的，先按分类看」
- 可选 0～3 条标「仅供参考」
- 列表为主；已降到全部时标题换成「这张图暂时对不上分类，先从全部里面挑」

### 6.7 看图失败

- 缩略图保留，旁注短句：「这张图看不了，换一张 jpg 或 png 试试。」
- 把握按低：下面仍列出金句（瀑布最终层或全部），每条可复制。
- 不出现重试转圈死循环；用户要再试就点「换一张」。

### 6.8 复制成功 / 失败

| 结果 | 轻提示 | 其他 |
|---|---|---|
| 成功 | 已复制，去微信粘贴就行 | 约 2 秒消失 |
| 失败 | 长按句子自己复制 | 该条正文保持可选中；不要用 `user-select: none` |

## 7. 反馈与手势（全站）

| 事件 | 反馈 |
|---|---|
| 保存成功 | 输入框清空 + 新卡片出现，无弹窗 |
| 空点保存 | 按钮本就禁用；若仍触发，输入框轻晃 +「先写一句」 |
| 重复句 | 轻提示「库里已有这句」，不新增 |
| 超 500 字 | 输入即截停在 500（编辑里），保存按钮在超限时禁用；列表保存路径阻止并提示 |
| 删除 | 必须确认，无滑动删除（第一期防误触） |
| 匹配超过约 10 秒 | 按 PRD 降级出列表，提示换成「这次没看清，先按分类看」 |

不做：页面切换大动画、彩带庆祝、匹配完成音效。

## 8. 轻量视觉规范

小团队没有视觉设计师时，开发按这些 token 实现，不要自行换成通用蓝紫 SaaS 风。气质按 **私人纸本**，不是运营后台。

| Token | 值 | 用途 |
|---|---|---|
| 背景 | `#F4EFE6` | 页底 |
| 纸面 | `#FFFBF4` | 卡片、输入、面板 |
| 墨色 | `#1C1917` | 主文字 |
| 次要文字 | `#78716C` | 说明、时间感 |
| 线 | `#E8E0D4` | 分割、未选芯片 |
| 主色 | `#C45C26` | 保存、配图页复制、底部悬浮按钮 |
| 主色文字 | `#FFFBF4` | 主按钮上的字 |
| 危险 | `#B42318` | 删除 |
| 标签底 | `#F0E7DB` | 场景 |
| 情绪底 | `#EDE4D4` | 情绪，可与场景同系，靠文字区分 |

**字体已锁定为摘录风：** 按钮、导航、说明用黑体（`Noto Sans SC` / 系统黑体）；金句正文、录入框用宋体（`Noto Serif SC`，回退 `Songti SC`）。

金句正文 17px，行高 1.5；说明 13px；按钮 16px。同一页里不要把按钮也改成宋体。

圆角：卡片 16px，按钮 12px，芯片 999px。间距以 8 的倍数：16 页边、12 卡片内、24 区块之间。

主按钮实心主色；次按钮空心或文字。同一视线里只出现一个实心主按钮。

## 9. 原型说明

打开 `docs/prototype/index.html`（用浏览器直接打开即可）。

顶部黄色条是 **设计评审用的状态机**，正式产品里没有。默认打开是太阳封面：点太阳写字，在封面上滑进入列表。再用「查看状态」把其余状态翻一遍：

片语：空库、分类中、分类完成、其他+建议、有数据、筛选无结果、编辑、删除确认。  
按图配文：空库、未上传、匹配中、把握高/中/低、看图失败、复制成功、复制失败。

你也可以在「有数据」状态下自己贴一句、点保存，体会主流程。原型分类是按关键词瞎猜的，**不代表上线后的模型**。

## 10. 给下一步的输入

技术方案必须遵守的界面约束：

- 只有这 2 页，编辑用面板，不用第三套导航。
- 保存与分类解耦：界面先有卡片，标签后到。
- 配图页复制按钮旁的正文可选择。
- 断网、看图失败的文案和布局按第 6.7、6.8 节，不要换成系统 alert。

下一步是 **第 5 步：技术方案**——在这些界面约束下选怎么存数据、怎么调用模型，仍然先写文档。
