## 1. 这场会是干什么的

需求评审找的是「产品会不会做成两个样」。  
技术评审找的是「两个人按这份方案写，会不会写出两套实现」。

三个目的：

1. 接口、超时、失败码有没有唯一口径  
2. 安全上有没有把密钥或模型代理暴露出去  
3. 测得出来：瀑布、清洗、降级能否不依赖真模型单独验  

结论同样是：通过 / 有条件通过 / 打回。本次 **有条件通过**，会后已写入技术方案 v0.2。

## 4. 评审发现

### 4.1 必须改方案（已回写 v0.2）

**T-01 分类失败 HTTP 码左右摇摆**

原文「可以 200 带其他，也可以 503」。前端会写成两套。

决议：

- 模型调用失败、超时、JSON 解析失败：接口仍 **HTTP 200**，body 为两轴「其他」+ `ok: false`  
- 请求本身不合法（没 text）：**HTTP 400**  
- 前端：保存从不看分类接口成败；收到 `ok: false` 或网络错误，标签保持/设为其他  

看图 `/api/look` 相反：失败必须能区分「图不行」和「模型没看清」，用 HTTP 200 + `ok: false` + `error` 枚举；非法文件 **400**。

**T-02 看图的场景数量没定**

金句场景是 1～2 个。图如果也乱回 2 个，瀑布「交集」会变宽、把握虚高。

决议：看图 **恰好 1 个场景 + 1 个情绪**。和金句做交集时，图的那一个场景对金句的数组即可。

**T-03 打开两个标签页会互相覆盖**

两个页签各改库，后写入的覆盖先写入的。第一期可接受，必须写成已知限制，并规定：**每次写入前读出再改再写**（read-modify-write），降低「后写整份旧快照」的概率。不做跨页实时同步。

**T-04 服务若监听 0.0.0.0，等于公开的付费模型代理**

第一期无鉴权。任何人碰到端口就能刷 `grok-4.6`。

决议：开发环境服务 **只绑定 127.0.0.1**。文档写明：上公网必须另做门禁，本期不做部署方案。

**T-05 瀑布必须是无 UI 的纯函数**

否则测试只能点页面。

决议：独立模块，例如 `matchQuotes(quotes, imageTags) → { level, recommended, related, title }`，不读 localStorage、不碰 DOM。切片 2 先写这函数的测试再接线。

**T-06 假分类和真分类的返回必须长得一样**

否则一切真模型就要改页面。

决议：`POST /api/classify` 的 JSON 形状固定。假实现也走这个接口（服务端环境变量 `FAKE_AI=1` 时不调模型，按关键词或一律「其他」）。前端始终只打 `/api/classify`，不要在页面里写第二套猜词。

**T-07 损坏的 localStorage 会让整站白屏**

决议：读失败则视为空库并打一条控制台警告，不 throw 到 Vue 根上。不自动备份。

**T-08 看图超时两层数字要对齐**

决议：前端 `AbortController` **10 秒**（对用户、对 PRD）。服务端调模型 **8 秒**。前端超时后按低把握降级，不把迟到的成功结果再盖上去（忽略迟到响应）。
