## 1. 这场会是干什么的

需求评审不是再脑暴功能，也不是开始讲 Vue、数据库。

三个目的：

1. **找洞**：主流程能走，异常、边界、互相打架的句子有没有写清。
2. **挡范围**：有没有人想把社区、生成文案、小程序塞进来。
3. **让下游能接**：设计知道画几页、几种状态；开发知道规则；测试知道怎样叫通过。

评审结论只有三种：通过 / 有条件通过（改完那些点再算过）/ 不通过（需求没齐，打回重写）。

本次是 **有条件通过**，条件在会后已消化进 PRD v0.2，不必再开一轮。

## 4. 评审发现

优先级：

- **必须改 PRD**：不改的话，设计和开发会做出不一样的产品
- **写入已知限制**：第一期就这样，不要假装能做到
- **留给技术方案**：产品行为已定，实现交给第 5 步
- **不做**：提出来了但挡回去

### 4.1 必须改 PRD（已回写 v0.2）

**R-01 持久化口径打架**

- 分析文档写过「换浏览器也不能当没发生过」。
- PRD 又写无登录，实现方式交给技术。
- 没有登录却要求换浏览器、换手机数据还在，等于偷偷做账号或云同步，第一期会爆。

决议：P0 只验收 **同一浏览器** 刷新、关掉再打开，金句还在。换浏览器、换手机、Safari 与微信内置浏览器互相换，第一期不验收。

**R-02 「相关分类」没定义，开发会各写各的**

PRD 只说「相关分类全部文案」，没说图是「夜色城市 + 松弛治愈」时，列表按 **同时命中** 还是 **命中任一**。

决议：放宽瀑布，按这一层一层降，直到有句子可看：

1. 场景命中（图的场景与金句场景有交集）**并且** 情绪相同  
2. 仅场景命中  
3. 仅情绪相同  
4. 全部金句  

「相关列表」展示当前降到的那一层的全部结果。禁止直接空白。

**R-03 把握高 / 中 / 低无法验收**

没有产品定义，测试写不出用例，开发只能拿模型分数瞎填。

决议（只看库和标签，不看模型内部分数）：

| 把握 | 何时 |
|---|---|
| 高 | 图抽出的场景、情绪都不是「其他」，且库里至少 1 条能「场景有交集且情绪相同」 |
| 中 | 对得上一轴（只场景或只情绪），或图有一轴是「其他」但另一轴能对上库 |
| 低 | 其他情况（图两轴都是其他、库里对不上、看图失败） |

展示仍按原 PRD 的高/中/低表格，本表只解决「什么时候算哪一档」。

**R-04 P0 缺少排序规则**

「最多 3 条推荐」没说谁排前面。

决议：P0 按匹配层级排（两轴命中 > 只场景 > 只情绪 > 其他），同一层按创建时间新的在前。刚用过的降权是 P1，本期推荐区可以不管。

**R-05 匹配理由写成了 P1，高把握表格里又写了「夜色城市 · 松弛治愈」**

决议：P0 推荐区标题用固定句「比较适合这张图的几句」，把握低时用固定句「没找到特别贴的，先按分类看」。带出具体场景/情绪标签是 P1（R9）。

**R-06 「其他」能否和真实场景并存**

「美食 + 其他」没有业务含义。

决议：场景里一旦出现「其他」，不能再配第二个场景。自动分类若给了真实场景，就不要再带「其他」。用户编辑时也遵守。

**R-07 分类还在转，用户已经去改分类**

决议：用户保存的分类优先。进行中的自动分类结果丢弃，不得盖住用户刚改的值。点建议标签，视为用户指定。

**R-08 重复、字数、连点**

- 重复：去首尾空白（含换行）后，字符串完全一样才算重复。中间多一个空格算另一句。第一期不做「模糊查重」。
- 500 字：按字符，含标点和换行。超了阻止保存，不悄悄截断（避免用户以为存进去了其实少半句）。
- 连点保存：同一正文不能因此出现两条。

**R-09 离线保存写得过满**

「网络失败时保存金句应尽量成功」会逼技术方案做成离线优先，第一期过重。

决议：P0 验收 **有网络时保存必成功**。无网络不作为 P0。看图、自动分类允许依赖网络；断网时配图页走已有降级文案，能列出本地已有金句则列出，列不出就说明网络原因并引导稍后再试——但库非空且数据已在本地/当前会话能读到时，仍优先给全部列表。

### 4.2 写入已知限制（不假装第一期能做到）

| 限制 | 对用户的含义 |
|---|---|
| 无登录 | 换手机、换浏览器，库可能是空的 |
| 微信内置浏览器 | 复制按钮可能失败，必须让句子能长按选中 |
| HEIC | iPhone 相册常见；产品要求技术方案优先支持，实在不行要人话提示换 jpg/png，且库非空时仍给列表 |
| 不长期存图 | 刷新配图页，当次图和当次结果可以消失，这是符合隐私的 |

### 4.3 留给技术方案（第 5 步再拍）

- 金句存在浏览器里还是服务端（P0 只验同一浏览器还在）。
- 自动分类、看图用哪个模型、超时怎么切。
- HEIC 在浏览器里怎么转。
- 图片上传前是否压缩（产品允许压缩，不展示原图像素）。
- 分类和看图如何打桩，方便测试覆盖降级（测试提出，技术评审落实）。

### 4.4 会上提出来、明确不做的

| 提议 | 结论 |
|---|---|
| 加登录，顺便跨设备 | 不做。那是账号系统，第一期禁止 |
| 微信小程序 | 不做。PRD 已写第一期 Web |
| 看图失败就让 AI 写一句新的 | 不做。与「只检索自己的句子」冲突 |
| 模糊查重、近义句合并 | 不做。第一期精确重复即可 |
| 设置页、主题切换 | 不做 |
