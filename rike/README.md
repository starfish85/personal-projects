# 日课

对着铺满屏的谱练吉他：点一下记一遍，卡住了翻自己的乐理图。到目标遍数会显示「今日练习吉他已完成」。

当前是能扫码打开的手机网页。微信小程序账号下来后，页面可以按同一信息架构再迁一层。

这是按企业流程走的练习项目：先写清问题，再写 PRD 和技术方案，再按切片开发。文档在 `docs/`。

## 现在能做什么

- 自定义目标遍数，大按钮 +1 / −1，跨日自动清零
- 到达目标后显示「今日练习吉他已完成」，多练几遍也允许
- 上传多页曲谱，全屏查看，拖动、双指缩放、按钮缩放
- 在谱上画笔 / 换色 / 粗细 / 橡皮 / 撤销，标注跟着谱走
- 乐理笔记另存；练谱时打开覆盖层，关掉谱还在原位置
- 任务可自己添加、改名、换色、暂停、归档；日历按当天任务显示进度
- 支持完成日期、长期任务、周几重复、子任务、模板化新建、番茄钟 / 正计时、作品墙
- 可选云同步（邮箱登录）：任务、进度、日记文字跨设备；图片仍只在本机，见 `docs/04-云同步.md`
- 导出 / 导入备份（数据只在当前浏览器，清缓存会丢）

## 在电脑上打开

```bash
cd rike
npm install
npm run dev
```

终端会给出本地地址。同一 Wi-Fi 下，手机浏览器打开它显示的局域网地址（形如 `http://192.168.x.x:5174`）。

- 云同步只同步文字、任务和进度，不同步图片。任务里的周几重复、完成日期、长期开关都会同步。换手机、换浏览器、清微信缓存前请导出备份。
