# 日课

对着铺满屏的谱练吉他：点一下记一遍，卡住了翻自己的乐理图。到目标遍数会显示「今日练习吉他已完成」。

当前是能扫码打开的手机网页。微信小程序账号下来后，页面可以按同一信息架构再迁一层。

这是按企业流程走的练习项目：先写清问题，再写 PRD 和技术方案，再按切片开发。文档在 `docs/`。

## 现在能做什么

- 自定义目标遍数，大按钮 +1 / −1，跨日自动清零
- 到达目标后显示「今日练习吉他已完成」，多练几遍也允许
- 上传多页曲谱，全屏查看，拖动、双指缩放、按钮缩放
- 在谱上画笔 / 换色 / 粗细 / 橡皮 / 撤销，标注跟着谱走
- 乐理笔记另存；练谱时打开覆盖层，关掉谱还在原位置
- 任务可自己添加、改名、换色、暂停、归档；日历按当天任务显示进度
- 支持完成日期、长期任务、周几重复、子任务、模板化新建、番茄钟 / 正计时、作品墙
- 可选云同步（邮箱验证码登录）：任务、进度、日记、曲谱和打卡图跨设备，见 `docs/04-云同步.md`
- 同一天两台手机都加遍数时取较大值，不会把两边相加
- 加到主屏幕后可开到点推送（微信网页里不行）；页面开着时仍会响
- 未登录时仍可导出 / 导入备份（清缓存会丢本机数据）
- 已做成 PWA：Safari 分享 → 添加到主屏幕；Chrome 菜单 → 安装应用。加到主屏幕后可离线打开已缓存的页面（云同步、推送仍需网络）

## 在电脑上打开

```bash
cd rike
npm install
npm run dev
```

终端会给出本地地址。同一 Wi-Fi 下，手机浏览器打开它显示的局域网地址（形如 `http://192.168.x.x:5174`）。

## 加到手机主屏幕（PWA）

用 Safari / Chrome 打开上面的固定网址（不要用微信内置浏览器）：

- iPhone：分享按钮 → **添加到主屏幕**
- Android Chrome：菜单 → **安装应用** 或 **添加到主屏幕**

装好后图标是曲谱，全屏打开，没有浏览器地址栏。第一次打开需要网络，之后没网也能进已经缓存过的页面。曲谱图片和云同步仍要联网。

## 已知限制

- 登录后图会进云端。没登录时曲谱和打卡图只在这台浏览器，清微信缓存会丢，请导出备份。
- 到点推送需要加到主屏幕并按 `docs/04-云同步.md` 配 VAPID；微信内置浏览器通常收不到。
- GitHub Pages 在微信里可能偏慢。
