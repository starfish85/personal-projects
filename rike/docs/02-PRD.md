## 2. 产品一句话

私人练琴台：对着铺满屏的谱练习，点一下记一遍，卡住了就翻自己的乐理图；到遍数即宣告今日完成。

## 3. 信息架构

第一期只有 **3 个主页面**，不要做成后台。

```text
日课
├── 今日练习（默认页，场景 A / D / E）
│   ├── 标题：练习吉他
│   ├── 计数：当前 / 目标
│   ├── 大按钮 +1、次按钮 −1
│   ├── 改目标
│   ├── 完成态文案
│   └── 入口：打开曲谱、打开笔记、备份
├── 曲谱（全屏，场景 B / C）
│   ├── 多页曲谱
│   ├── 拖动 / 缩放 / 涂写
│   ├── 悬浮计数
│   └── 笔记覆盖层（不是新路由）
└── 笔记库（场景 C 的管理）
    ├── 乐理图片列表
    └── 增 / 删 / 全屏看
```

底部或首页提供三个入口的切换。曲谱页是沉浸式，用页内返回，不套底部 Tab 挡谱。

不提供：注册登录页、发现页、任务列表、设置里的账号开关。

## 4. 全局规则

这些规则全站生效，写代码时不要每个页面各解释一遍。

### 4.1 用户与数据

- 第一期无注册、无登录、无多人。
- P0 持久化：同一浏览器里刷新、关掉再打开，目标、今日遍数、曲谱、标注、笔记还在。
- 换浏览器、换手机、Safari 与微信内置浏览器互切，第一期不验收（无登录做不到稳定同步）。
- 存在哪里由技术方案决定。P0 验收有存储配额时保存必成功；配额满要有明确失败提示，不得静默丢图。

### 4.2 日期与「今日」

- 「今日」= 设备本地日历日，格式 `YYYY-MM-DD`。禁止用 UTC 日期，避免晚上 8 点变成第二天。
- 跨日：遍数归 0，完成态取消；目标遍数、曲谱、标注、笔记不动。
- 应用从后台回到前台时，若日期已变，按新的一天处理。
- 不允许用户手工改「今天是哪一天」（那是测试手段，不是产品功能）。

### 4.3 计数

- 目标遍数：整数，最小 1，最大 999。默认 **10**。
- +1 每次加 1；−1 每次减 1，到 0 停止，不落到负数。
- `当前 >= 目标` 即为完成。完成文案固定为：**今日练习吉他已完成**。
- 完成后仍可 +1，文案保持，数字显示 `已完成 · 21/20` 这种形态（当前 / 目标都要看见）。
- 从完成减回到目标以下：完成文案消失，`completedAt` 清掉。
- 改目标：立即按新目标重算完成态。例如当前 8、目标从 10 改成 5，立刻变为已完成。
- 连点 +1 必须每一下都算，不得节流丢次数。

### 4.4 图片

- 支持 jpg / png / webp。若手机 HEIC 无法识别，提示「请换成 jpg 或 png」，不得生成空白图。
- 曲谱和笔记是两类资源，列表和存储都分开。不能做成一个相册让用户自己猜哪张是谱。
- 曲谱支持一首多页（一次选多张，按加入顺序为页序）。第一期不提供拖拽排序。
- 单张原文件建议上限 20MB；超过则拒绝并提示。上传后由技术压缩，产品只要求「打开不糊到看不清六线谱」。
- 删除曲谱某一页：二次确认；确认后该页图片和该页标注一起删除。
- 删除笔记：二次确认。

### 4.5 曲谱手势

- 浏览模式：单指拖动，双指缩放，按钮放大 / 缩小。
- 画笔 / 橡皮模式：单指写；**双指仍缩放拖动**（避免画着画着整页跑掉，也避免想缩放却画出一道杠）。
- 曲谱页禁止浏览器下拉刷新、禁止 iOS 弹性把整页拖走。
- 缩放后标注必须钉在谱的相对位置，不得「图走了、线还在原地」。
- 初始进入某一页：整页 contain 进屏幕（谱完整可见），不强制铺满导致裁切。

### 4.6 标注

- 工具：画笔、橡皮、撤销、清空本页。
- 画笔至少 4 种颜色（墨、红、蓝、黄）和 3 档粗细。
- 撤销：撤销上一笔（含橡皮的一笔），直到没有。
- 清空本页：二次确认「清掉这一页上的记号？谱还在。」
- 标注随该页图片持久化。换页再回来，记号还在。
- 第一期不做：文字输入、箭头图形、图层、选区、形状识别。

### 4.7 笔记覆盖层

- 从曲谱页打开笔记，必须是覆盖层，禁止 `跳转到笔记页再返回`。
- 关掉覆盖层后，页码、缩放、位移、当前工具必须与打开前一致。
- 覆盖层里可以翻自己的乐理图；不在覆盖层里改曲谱。

### 4.8 文案原则

- 完成语用「今日练习吉他已完成」，不要「打卡成功」「任务 100%」这类通用待办腔。
- +1 按钮文案用「练完一遍」，不要「提交」「确定」。
- 空状态讲下一步做什么，不讲技术错误码。

### 4.9 备份（P1）

- 提供导出备份、导入备份。导出一份文件，里面有目标、历史天数遍数、曲谱、标注、笔记。
- 导入前二次确认「会覆盖本机现有数据」。
- P0 可以没有备份，但必须在界面或 README 写清：清缓存会丢谱。P1 强烈建议同一期后半段做掉。

## 5. 页面说明

下面的框图是结构，不是视觉稿。

### 5.1 今日练习

```text
┌─────────────────────────────────────┐
│  日课                               │
│  练习吉他                           │
│                                     │
│           7  /  20                  │
│                                     │
│      ┌───────────────────┐          │
│      │    练完一遍         │          │
│      └───────────────────┘          │
│         −1        改目标             │
│                                     │
│      今日练习吉他已完成              │
│                                     │
│      [ 打开曲谱 ]                   │
│      [ 乐理笔记 ]                   │
│      备份                            │
└─────────────────────────────────────┘
```

**P0 要素**

| 元素 | 行为 |
|---|---|
| 大数字 | 当前遍数，目标在旁边或下面，始终同时可见 |
| 练完一遍 | 主按钮，足够大，单手拇指可点；点一下 +1，立刻反馈 |
| −1 | 次要按钮；当前为 0 时不可用 |
| 改目标 | 打开输入，确认后立刻生效 |
| 完成文案 | 仅当 `当前 >= 目标` 显示 |
| 打开曲谱 | 进入曲谱页；若还没有谱，进入后走曲谱空状态 |
| 乐理笔记 | 进入笔记库 |

**空状态（今天 0 遍，未完成）**

数字是 `0 / 目标`。不显示完成文案。主按钮仍可用。

**还没有曲谱时**

「打开曲谱」仍可进，曲谱页自己承担空状态，不在首页拦截。

### 5.2 曲谱

```text
┌─────────────────────────────────────┐
│ ←  1/3     7/20  +     笔记         │
│                                     │
│                                     │
│            （谱占满其余空间）         │
│                                     │
│                                     │
│  [浏览] [画笔] [橡皮]  色  粗  撤销  │
│  [页缩略图]              清空  加页  │
└─────────────────────────────────────┘
```

**P0 要素**

| 元素 | 行为 |
|---|---|
| 返回 | 回今日练习；本次缩放可丢，谱和标注不能丢 |
| 页码 | 当前页 / 总页 |
| 计数胶囊 | 显示当前/目标；点 + 等同「练完一遍」 |
| 笔记 | 打开笔记覆盖层 |
| 浏览 / 画笔 / 橡皮 | 互斥模式 |
| 加页 | 从相册加一张或多张，追加到末尾 |
| 页缩略图 | 点一下换页；删除走确认 |
| 缩放按钮 | 在工具条提供 + / −，给不习惯双指的情况 |

**空状态（0 页曲谱）**

> 还没有曲谱。拍一张谱或从相册选，练习时它会铺满屏幕。

主操作：上传曲谱。

**工具条与谱的关系**

工具条叠在谱上，不把谱挤出屏幕。被挡住的部分靠拖动露出。

### 5.3 笔记覆盖层（从曲谱打开）

全屏或近全屏。顶部「关闭」必须明显。关闭后回到 5.2 的原状态。

无笔记时：

> 还没有乐理笔记。先去存几张要记的图，卡住时就能翻。

并提供「去添加」（可在覆盖层内直接上传，不必强迫用户关掉再走笔记库）。

### 5.4 笔记库

网格列出乐理图。点击全屏查看（可缩放）。添加、删除。

空状态：

> 把要背的乐理拍下来。练谱时随时能翻，不用离开曲谱。

## 6. 字段（给开发和测试对齐，不是接口文档）

| 对象 | 字段 | 含义 |
|---|---|---|
| 任务 | id, title, target | 第一期写死 id=`guitar`，title=`练习吉他` |
| 当日进度 | date, count, completedAt | date 本地日；count ≥ 0；完成后才有 completedAt |
| 资源 | id, role, 图片, 宽高, 顺序, 创建时间 | role 只能是 `sheet` 或 `note` |

二期若增加任务，禁止把 `guitar` 写进组件文件名以外的业务判断里。完成规则、资源角色已经按通用字段建模，第一期 UI 可以写死标题。

## 7. 异常与边界

| 情况 | 产品行为 |
|---|---|
| 图片格式不支持 | 提示换成 jpg / png，已选中的其他张照常加 |
| 单张过大 | 提示太大，不加这一张 |
| 存储配额满 | 提示「手机给这个页面的空间不够了，删几张谱或导出后清理」，已成功的张保留 |
| 画到一半杀进程 | 已抬笔的笔画要在；未抬笔的那一笔可以丢 |
| 目标改成比当前更小 | 立刻完成 |
| 目标改成比当前更大 | 取消完成态 |
| 0 页时点换页、撤销、清空 | 无操作，不报崩溃 |
| 微信里打开 | 主路径可用；若文件选择器被限制，提示用右上角浏览器打开 |

## 8. 优先级

**P0（第一期必须）**

R1～R11 对应的计数、曲谱全屏、标注、笔记覆盖层、同浏览器持久化。R12 扫码打开。

**P1（同一期后半，可稍后几小时）**

- 导出 / 导入备份
- 曲谱页内直接加笔记（覆盖层空状态）
- 缩略图删除的手感打磨

**P2（不做，列入二期）**

任务列表、自定义辅助页、画画打卡、同步、小程序。

## 9. 主流程（验收时按此走）

1. 扫码打开 → 落在今日练习，当前 0，目标 10。
2. 改目标为 3。
3. 上传 2 张曲谱，进入全屏，能换页、缩放、拖动。
4. 画一笔红圈，缩放，笔还在原音符上。
5. 点「练完一遍」三次（首页或曲谱胶囊均可），出现「今日练习吉他已完成」。
6. 打开笔记覆盖层，加一张乐理图，关闭，谱的缩放和红圈都在。
7. 杀掉页面再打开：遍数 3/3、谱、红圈、笔记都在。
8. 把系统日期调到第二天再打开（或等到第二天）：遍数 0/3，谱和笔记还在。

## 10. 验收标准

测试按「能写进用例的句子」验收，不按「感觉挺顺」。

| 编号 | 标准 |
|---|---|
| A1 | 目标可改为 1～999 的整数，非法输入不能保存 |
| A2 | +1 / −1 后数字立刻变；刷新后与刚才一致 |
| A3 | 当前达到目标的当次操作后，完成文案可见 |
| A4 | 完成后继续 +1，文案仍在，数字继续涨 |
| A5 | −1 使当前 < 目标后，完成文案消失 |
| A6 | 本地日期变化后遍数为 0，目标不变 |
| A7 | 曲谱图在竖屏手机上完整可见（contain），不是只显示中心一块 |
| A8 | 双指放大后能拖到该页四个角 |
| A9 | 标注在缩放、换页往返、刷新后仍对齐原位置 |
| A10 | 撤销只去掉最后一笔 |
| A11 | 删除一页曲谱后，该页标注不再出现 |
| A12 | 曲谱中打开笔记再关闭，页码和缩放不变 |
| A13 | 曲谱与笔记列表互不混入 |
| A14 | 同一浏览器持久化：目标、当日遍数、图、标注 |
| A15 | GitHub Pages 的 https 地址可被手机摄像头扫开 |

## 11. 已知限制（写给评审，不要假装能做到）

- 无登录，换机等于新用户。
- GitHub Pages 在微信里可能加载偏慢。
- 清站点数据会丢谱；P0 用文案告知，P1 用备份兜底。
- 第一期不是小程序，没有微信右上角分享到会话的官方能力；分享就是发网址或二维码。
