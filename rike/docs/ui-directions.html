RIKE · UI DIRECTION

日课要高级，其实是选气质

现在的界面已经有了方向：暖棕底、文楷、琥珀按钮。它不像烂大街的蓝紫待办，但还停在「自己做的小工具」——图标是 CSS 画的，卡片重量一样，日期还是 2026-08-26，完成只是把整张卡变淡。 高级不是多加玻璃拟态，而是让「每天坐下练」这件事看起来被认真对待。下面四套都保留现有信息架构（主页 / 日记 / 日历 / 作品墙），只换气质。

现在为什么不够高级

  • 视觉层级平：所有任务一张卡，今天最该练的那项没有主角。
  • 材料假：平面色块 + CSS 图标，没有纸、铜、墨这些「物件感」。
  • 时间像数据库：ISO 日期、均匀字距标题，不像日课簿。
  • 完成态廉价：整卡变淡，而不是盖印、画圈、收进档案。
  • 品牌只用字距：文楷是好资产，但还没变成一套完整的仪式。
推荐默认 · 改动最小

A. 灯下琴房

把现有暖棕继续做精：台灯光、黄铜、谱纸。高级来自「今晚要练」的气氛，不是换一套皮肤。

气质 夜间琴房、仪式、私密
保留 深色、文楷、琥珀、现有结构
新东西 中文日期、今日进度环、色条卡片、浮动 Tab、完成盖印
风险 最低。看起来仍是日课，只是更值钱。

B. 宣纸日课

翻成浅色：宣纸、墨、朱印。曲谱本身就是纸，练的时候屏幕不再是黑洞。无印良品那种克制。

气质 手帐、文房、白天书桌
保留 文楷、任务列表、底部四栏
新东西 浅色纸底、朱砂完成、虚线装订感、印章品牌
风险 和现在反差最大；晚上练琴可能偏亮，要单独做曲谱全黑。

C. 静奢工具

炭黑、一根铜线、巨大数字。高级来自留白和精度，像 Linear / 苹果健身那种「什么都没画，但很贵」。

气质 精密仪器、克制、现代
保留 深色、任务数据、四栏
新东西 超大剩余数、发丝分割、细进度环、文楷只留在词标
风险 最容易做成又一个待办 App，日课的「课」味会变淡。

D. 杂志封面

每天打开像翻到新一页封面：巨大日期，一件主课铺满，其余收成目录。适合「今天只认真练一件」。

气质 独立杂志、封面、主次分明
保留 深色、文楷、任务模型
新东西 巨型日期、主课大卡、其余变索引行
风险 任务一多会挤；置顶/多课并行时要规定谁当封面。
