## Overview

你标了五处界面，外加「能不能加后端和 AI」。分成两层，**不要一次做完**：

1. **A 层（本机 UI，无新服务）**：日历三按钮粘连、云同步挪到底、点封面日期换日、去掉作品墙说明文案、卡片去彩边、左滑三色改成暖色盘。
2. **B 层（可选后端 + AI）**：能加，也值得加，但必须是「私人教练」而不是聊天机器人。密钥不能进 PWA。图仍只在本机。

日期切换的数据规则以 `docs/07` 为准（`practice.viewingDate`，禁止改写 `practice.date`）。本文只修正 **点哪里**（封面大字，不是已经不存在的右上角 `YYYY-MM-DD`），并收口其它视觉。

## Key Decisions

1. **点封面日期（八月 + 廿六），不是恢复右上角阿拉伯数字。** 热区是 `.cover-date`（kicker + day）。星期行仍展示，可点可不可点都行，默认 **整块可点**（含 `cover-cap`）以免拇指只打到字心。非今天：大字改 `--amber`，`cover-top` 右侧出 `回今天`（和归档箱叠在 `.head-actions`）。
2. **选日 UI 仍是 `docs/07` 的底部 sheet：昨天 / 今天 / 明天 + `type=date`。** 选中即换 `viewingDate`，不跳日历 Tab，不复制日历二次点击。
3. **`SyncBar` 挪到首页滚动内容最底部**（列表和日记行之后、FAB 之前）。FAB / Tab 仍是 fixed。备份 nag **留在封面下、列表上**——那是警告，不能沉底看不见。
4. **作品墙列表删掉 `.lead` 那句。** 空态那句「还没有可回看的图片墙…」保留（没卡片时才需要）。任务卡上的 `N 张图片 · 最近 MM-DD` 保留。
5. **普通任务卡去掉左侧 inset 彩边。** 颜色仍用圆点 `.dot`。主课卡（`--paper`）本来就没有这条边，保持。
6. **左滑三键改成暖色盘，不引入新色相。** 修改 = `--bg-soft` + `--paper`；归档 = `--seal`（已有朱砂，比高饱和蓝灰更贴）；置顶 = `--amber` + `--ink`（现网，不动）。不要三块都做成 amber，分不清危险操作。
7. **日历三按钮：`.task-actions` + `column-gap: 20px`。** 出现条件、跳转、`v-if` 一字不改。不要胶囊。首页卡片不加这三项。
8. **后端可以加，但是可选层，不是把日课改成必须联网。** IndexedDB 仍是真相；现有 Supabase 继续只同步文字和进度。
9. **AI 走 SpaceXAI（xAI API：`XAI_API_KEY`、`https://api.x.ai/v1`、默认 `grok-4.5`）。** 密钥只在服务端。PWA 里不写 key、不直连 `api.x.ai`。
10. **第一批 AI 只做「今日/本周文字复盘」，不碰曲谱图、不做人脸/动作识别、不加社交。** 含金量来自「本地日课 + RLS 云同步 + 带鉴权的推理网关」，不是多一个对话框。

## A. 本机 UI

### A1. 日历任务行按钮

文件：`src/pages/Calendar.vue`

四个 `open inline` 包进：

```html
<div
  v-if="isToday || isFuture || taskHasGallery(task)"
  class="task-actions"
>
  <!-- 现有四个按钮，去掉 class inline，v-if 不变 -->
</div>
```

```css
.task-actions {
  display: flex;
  flex-wrap: wrap;
  column-gap: 20px;
  row-gap: 4px;
  margin-top: 10px;
}
.task-actions .open { margin-top: 0; min-height: 44px; padding: 0 2px; }
```

只有一个按钮时不要空槽。过去日仅「查看作品墙」时左对齐即可。

### A2. 云同步到底部

文件：`src/pages/Home.vue`

顺序：

```
cover
备份 nag（若有）
模式说明（仅 past/future，docs/07）
任务列表（主课 + 其余）
日记行（past/today）
SyncBar          ← 从封面下挪到这里
FAB / 弹窗 / 归档箱
```

`SyncBar` 默认折叠。未登录时不要为了「底部」再自动展开挡列表——现网 `open = !config && !cloud.user` 在有 env 云配置时本来就是折叠。保持。

窄屏：展开后备份按钮仍在 SyncBar 内部最下（PR1 已做）。

### A3. 点封面换日

热区与展示：

```html
<button type="button" class="cover-date" :class="{ away: viewMode !== 'today' }" @click="pickerOpen = true">
  <span class="cover-kicker">{{ cover.month }}</span>
  <span class="cover-day">{{ cover.day }}</span>
  <span class="cover-cap">{{ cover.weekday }} · {{ remainingCopy() }}</span>
</button>
```

`cover = formatCoverDate(viewingDate)`，**不要**再用 `practice.date`。

非今天：`.cover-date.away .cover-day { color: var(--amber) }`；`回今天` 在 `.head-actions`，只 `setViewingDate(today)`。

`remainingCopy()` 按模式：今天维持「还剩 N 课 / 今日已课 / 今天没有安排」；过去「这天的记录」；未来「已安排 N 课」。不要写长说明。

Sheet、`viewingDate`、三种模式列表 / FAB / 勾子 / 左滑 / 日记行：整节照 `docs/07` 实现，本文不重写函数。

主课卡文案「今日主课」在 past/future 改成「这天主课」/「将做」；CTA 非今天不要写「打开曲谱」去 `/task`（07：非今天不进详情）。未来点主课 = `openEdit`；过去点主课无跳转（有子任务则展开只读）。

### A4. 去掉作品墙说明书

文件：`src/pages/Gallery.vue`

删：

```html
<p class="lead">这里会列出所有需要图片打卡的任务，每个任务都有自己独立的墙。</p>
```

及对应 `.lead` 样式。空态、卡片副文案不动。日历 / 详情里不要新加类似句子。

### A5. 去卡片彩边

文件：`src/pages/Home.vue`

`.card` 去掉 `box-shadow: inset 3px 0 0 var(--task, var(--amber))`。`--task` CSS 变量若只为这条边服务，可从 swipe 上删；主课卡强调仍靠纸色，不靠边。

任务色：圆点保留。不要改成全卡染色。

### A6. 左滑配色

```css
.act.edit { background: var(--bg-soft); color: var(--paper); }
.act.del  { background: var(--seal);    color: var(--paper); }
.act.pin  { background: var(--amber);   color: var(--ink); }
```

`--seal: #c45c3a` 已在 `global.css`（主课「印」）。归档用它，避免 `--danger` 的偏橙红和封面朱砂打架。三个键仍 64px 宽、`ACTION_W = 192`。

不采用：三键同色不同透明度（看不出归档）；改回冷蓝（你已经觉得违和）。

## B. 后端与 AI（能否加、怎么加才有含金量）

**能加。** 现网已经有一层可选云（Supabase + 邮箱魔法链，`docs/04`）。缺的是「带密钥的服务端」，不是再搭一套 CRUD。

### 为什么不要把推理塞进 Vite

PWA 打到 GitHub Pages。任何写在前端的 `XAI_API_KEY` 都会被拿走。图片已经承诺不上传。所以：

| 放哪 | 行不行 |
|---|---|
| `rike` 前端直连 `api.x.ai` | 不行 |
| 本机 Ollama | 含金量低、微信里不可用 |
| **已有 Supabase 的 Edge Function** | 默认。登录用户才能调；key 在 function secret |
| 另起一台 Node | 能做，多一个运维面，本阶段不需要 |

鉴权：沿用现成 JWT。匿名用户：前端不展示「小结」入口，或本地规则摘要（无 LLM）。

### 第一批功能（实用 > 炫）

只做文字，payload 来自已经同步的 kv：任务名、当天 count/target/completedAt、日记文字、批注。**不传图片、曲谱、笔迹。**

1. **今日小结**（首页今天、日历今天各一个按钮「小结」）  
   输入：当天各任务完成态 + 日记（若有）。  
   输出：不超过 120 字的三句话：做了什么、缺什么、明天可执行的一句。  
   写入：可选「存进今天日记末尾」。默认先展示，用户点「写入日记」才存。
2. **周回顾**（日历周视图若未做，就用最近 7 个「应出现日」）  
   哪几课断了、哪几课连续。给下周只改一句建议（不要生成新任务对象，除非用户点「按此安排」——第一批 **不自动建任务**）。
3. **批注/日记润色**（详情批注旁、日记页一个「整理」）  
   把口语变成条目，不改事实、不发明遍数。

模型：`grok-4.5`（OpenAI 兼容 `https://api.x.ai/v1`）。温度低（0.3）。超时 20s，失败 toast「小结没写出来」，不影响打卡。

### 明确不做（B 层）

- 社交、排行、公开练习动态
- 把曲谱/打卡图送到云上给视觉模型「看谱」——和「图只在这台手机」冲突；真要做是另一份隐私方案
- 首页常驻聊天泡
- 自动改 `count` / 自动归档
- 为 AI 重写数据模型或放弃 IndexedDB
- 用 OpenAI / Anthropic / Gemini 作默认（SpaceXAI 不够再用兼容层换）

### 含金量怎么讲（工程，不是营销）

可落地的三层：

1. 本地：Vue PWA、IDB、按日课表、离线能打卡  
2. 同步：Supabase RLS，文字进度跨设备，图走备份文件  
3. 推理：登录后的 Edge Function 代理 LLM，最小必要字段、可关

比「加了个 ChatGPT 页面」硬：有鉴权边界、有数据分级、有失败降级。

### 数据与钱

- Function 入参：`{ date, tasks: [{ id, title, completion, count, target, done }], journal }` 当天切片，不传全库。  
- 出参：`{ summary: string }`。  
- 频率：每用户每天小结 ≤ 20 次（函数里按 `user_id + date` 计数），防把 key 刷爆。  
- 费用：短中文、一天几次，个人项目可忽略；key 放 Supabase secrets，不进 git。

### 和 A 层的关系

没有 B 也能发 A。没有登录也能用日课。小结按钮：`cloud.user` 才显示。

## 风险

| 风险 | 级 | 缓解 |
|---|---|---|
| 封面热区误触（大字好点也容易误点） | 中 | 点开的是 sheet 不是立刻换昨天；遮罩可关；有回今天 |
| SyncBar 沉底找不到 | 低 | 折叠摘要仍叫「云同步」；备份 nag 仍在上 |
| 左滑归档色不够「危险」 | 低 | `--seal` 仍是红系；文案「归档」不变 |
| Edge Function 冷启动慢 | 中 | 按钮「小结中」；超时 toast |
| 把日记全文送给模型 | 中 | 截断 2k 字；系统提示「不要外传」只是提示，真正靠不把图和密钥放前端 |
| 未登录以为 AI 坏了 | 低 | 无 user 不渲染按钮 |

`docs/07` 里「改 practice.date / 过去用 tasksOnDate / 看昨天勾了今天」三条高危仍然有效。

## 验收（A 层，390 宽）

1. 日历今天画画：三个按钮能分开读、分开点，间隙约 20px。  
2. 今天仅「打开任务」时不留两个空位。  
3. 首页先看到封面和课，滑到底才是云同步；备份 nag 仍在列表上方。  
4. 点廿六（或整块封面日期）出「看哪一天」；昨天/今天/明天换列表；逻辑同 `docs/07` 验收 1–15。  
5. 作品墙任务列表没有那句「这里会列出所有…」。无墙时仍有空态。  
6. 其余日课卡片左侧无色条，圆点还在。主课纸色卡不变。  
7. 左滑：修改深褐底浅字、归档朱砂、置顶琥珀；功能仍是修改/归档/置顶。  

B 层验收（有 key、已登录）：点小结 20s 内出 ≤120 字；失败不丢打卡；未登录无入口。
