# 日课 · 云同步（只同步文字和进度，不同步图片）

免费档够一个人先用。图仍只在本机；换设备能看到哪天练过、画过、日记写了什么。

## 建项目

1. 打开 https://supabase.com 注册（免费）。
2. New project，记下 URL 和 `anon` `public` key。
3. SQL Editor 里执行 `supabase/schema.sql` 全文。
4. Authentication → URL Configuration，把 Redirect URLs 加上：
   - `https://starfish85.github.io/personal-projects/rike/`
   - `http://localhost:5174/`
5. 打开日课首页，展开「云同步」：
   - 第一次填 URL 和 anon key，保存后页面会刷新。
   - 再填邮箱，点「发送登录链接」。
   - 邮箱里点登录链接，回到日课后可点「立即同步」。

anon key 本来就可以放在网页里，不是私钥。私钥 `service_role` 不要填、不要提交。

## 同步范围

同步：
- 任务列表、模板、组件配置
- 完成日期、长期任务、暂停 / 归档、提醒时间
- 每日完成状态、计数、子任务每日完成状态
- 日记文字、批注文字

不同步：
- 图片打卡图片
- 曲谱图片、笔记图片
- 图片批注笔迹
- 日记图片

图片需要用「导出备份」迁移到新设备。
