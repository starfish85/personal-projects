# 日课 · 云同步

免费档够一个人用。登录后文字、进度、曲谱、打卡图、日记图都会上云；换手机登录再点同步即可，不必先导出 JSON。本机 IndexedDB 仍是缓存，没网也能练。

## 建项目

1. 打开 https://supabase.com 注册（免费）。
2. New project，记下 URL 和 `anon` `public` key。
3. SQL Editor 里执行 `supabase/schema.sql` 全文（可重复执行）。
4. Authentication → URL Configuration，把 Redirect URLs 加上：
   - `https://starfish85.github.io/personal-projects/rike/`
   - `https://starfish85.github.io/personal-projects/rike/index.html`
   - `http://localhost:5174/`
   - `http://localhost:5174/index.html`
5. 免费档默认邮件模板是锁住的（要自备 SMTP 才能改正文）。**不用改模板。** 邮件里会有 Sign in 链接，点它即可。
6. 打开日课，展开「云同步」：填 URL 和 anon key → 填邮箱 → 发送登录邮件。
7. 打开邮箱，**不要点** Sign in。长按链接选复制，回到日课粘贴，点「用这个链接登录」。微信里直接点开会丢登录信息。

anon key 可以放在网页里，不是私钥。`service_role` 不要填、不要提交。

## 同步范围

同步：

- 任务（按任务合并，不是整表覆盖）
- 完成日期、长期 / 周几、暂停 / 归档、提醒、置顶
- 每天遍数、打卡、子任务完成
- 日记文字、任务笔记
- 曲谱、打卡图、日记图、乐理图，以及谱上的笔迹

## 冲突规则

| 情况 | 结果 |
|---|---|
| 两台手机改了**不同任务** | 两边都保留 |
| 两台改了**同一条任务**（名字、目标、周几） | 谁的 `updatedAt` 更晚用谁的 |
| 同一天两边都给吉他 **+1** | 取较大遍数，**不会 6+7=13** |
| 一边把今天勾掉（计数变 0）且时间更晚 | 以清零为准 |
| 一边删了一张谱 | 墓碑同步到另一台，两边都删 |

## 到点提醒（页面关掉也能响）

页面开着时，仍用原来的前端定时器。要人走了还响：

1. 把日课 **加到主屏幕**（Safari / Chrome）。微信内置浏览器一般不能网页推送。
2. 生成 VAPID 钥匙（只做一次）：

```bash
npx web-push generate-vapid-keys
```

3. Supabase Dashboard → Edge Functions → Secrets，加上：

| 名 | 值 |
|---|---|
| `VAPID_PUBLIC_KEY` | 公钥 |
| `VAPID_PRIVATE_KEY` | 私钥 |
| `VAPID_SUBJECT` | `mailto:你的邮箱` |
| `CRON_SECRET` | 自己编的一长串 |

4. 本机已装 [Supabase CLI](https://supabase.com/docs/guides/cli) 后，在 `rike` 目录：

```bash
npx supabase login
npx supabase link --project-ref 你的项目编号
npx supabase functions deploy push-config
npx supabase functions deploy send-reminders --no-verify-jwt
```

5. 把 `supabase/cron.sql` 里的 URL、anon key、`CRON_SECRET` 换成你的，在 SQL Editor 执行。

6. 日课里登录后点「打开到点提醒」，允许通知。

没配 VAPID 时，同步和传图照常工作，只是关页面不会推送。免费项目 7 天完全没人访问会暂停，你每天打开日课就不会停。
